House Manager 🏡

Una piattaforma web moderna per la gestione di annunci immobiliari, appuntamenti e consulenze. 

**Progetto Universitario**
Realizzato da: **Attilio Luigi Apreda** (Mat. 0124003105)

---

## 🚀 Caratteristiche Principali

*   **Gestione Annunci:** Pubblicazione, visualizzazione e ricerca di immobili con dettagli completi (metratura, stanze, ascensore, garage, ecc.) e galleria fotografica.
*   **Autenticazione Sicura:** Registrazione e login utente con password crittografate (tramite `werkzeug.security`) e gestione delle sessioni.
*   **Appuntamenti & Consulenze:** Sistema integrato per richiedere visite agli immobili e prenotare consulenze immobiliari.
*   **Interfaccia Responsiva:** Design pulito e adattabile a qualsiasi dispositivo (Desktop/Mobile) realizzato con Bootstrap.
*   **Sicurezza:** Gestione delle variabili d'ambiente e credenziali tramite file `.env` nascosto.

## 🛠️ Stack Tecnologico

**Backend:**
*   Python 3.14
*   Flask (Web Framework)
*   MongoDB Atlas (Database NoSQL)
*   MongoEngine (ODM)
*   JWT Extended (Autenticazione)

**Frontend:**
*   HTML5 / CSS3
*   JavaScript (ES6+)
*   Bootstrap
